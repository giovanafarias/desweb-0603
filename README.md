# desweb-0603

Construa uma página de portifólio, responsiva, utilizando os conceitos de
Transformação, Animação, Media Query e Grid. A página deve conter a
seguinte estrutura: < header >, < main > e < footer >. Dentro da tag < main >
devem estar as seções de Hero, Projetos e Contato. Para responsividade
utilize os seguintes breakpoints: @media (max-width: 768px); e @media
(max-width: 480px).

Link de Referência: https://gileduardo.com.br/ifpr/dw/downloads/portifolio/
